# LimbLab 假肢科普网站

Open `index.html` for the English site. Use the EN / 中文 switch to move between the full English and Chinese versions. The site uses plain HTML, CSS, and JavaScript with no installation required.

## 已实现

- Full English default site with a complete Chinese version
- Visible EN / 中文 language switch
- Pink responsive design for desktop and mobile
- 假肢类型、肌电控制、感觉反馈、康复与伦理科普
- 肌电信号互动演示
- 误区折叠内容、三题知识测试、可搜索术语表
- 匿名反馈前端原型与隐私提示
- 学术和公共卫生来源链接
